在线商城优惠券与订单管理系统 PRD
文档版本： V1.0

产品类型： Web 电商平台

目标用户： 普通用户、商城管理员
1. 产品概述
本系统为用户提供在线商品浏览、购物车管理、优惠券领取与使用、订单提交及支付等功能。

用户可以浏览商品、加入购物车、领取优惠券并提交订单。管理员负责商品管理、优惠券配置及订单管理。

系统需要保证订单金额计算准确、优惠券使用规则正确，并避免并发操作导致库存或优惠券数据异常。
2. 用户角色与权限
角色	权限
普通用户	浏览商品、管理购物车、领取优惠券、下单、支付、取消自己的订单、申请退款
管理员	管理商品、库存、优惠券、查看所有订单、修改订单状态、处理退款

业务规则：
1. 未登录用户可以浏览商品，但不能领取优惠券、提交订单。
2. 普通用户只能查看自己的订单。
3. 普通用户不能修改其他用户的订单。
4. 管理员可以查看所有用户的订单。
5. 管理员操作需要经过身份认证。
3. 商品管理
3.1 商品列表
商品列表展示：
- 商品名称
- 商品图片
- 商品价格
- 商品库存
- 商品状态
业务规则：
1. 商品状态分为上架、下架。
2. 下架商品不能被加入购物车。
3. 库存为 0 的商品显示售罄状态。
4. 商品价格必须大于 0。
5. 商品名称不能为空。
3.2 商品库存
1. 用户提交订单时需要检查商品库存。
2. 订单支付成功后扣减对应商品库存。
3. 商品库存不能小于 0。
4. 多个用户同时购买同一商品时，不能出现超卖。
5. 管理员可以手动调整商品库存。
4. 购物车管理
4.1 添加商品
1. 用户可以将商品加入购物车。
2. 同一用户重复添加同一商品时，合并为一条购物车记录并累加数量。
3. 商品下架后不能继续添加到购物车。
4. 添加商品时需要校验商品库存。
4.2 修改购物车
1. 用户可以修改商品购买数量。
2. 购买数量必须为正整数。
3. 购买数量不能超过当前商品库存。
4. 用户可以删除购物车中的商品。
5. 商品价格发生变化时，购物车应展示最新商品价格。
5. 优惠券管理
5.1 优惠券类型
系统支持两种优惠券：
类型	说明
满减券	满足最低消费金额后，减免固定金额
折扣券	满足最低消费金额后，按指定折扣计算

5.2 优惠券领取
1. 用户可以领取处于有效状态的优惠券。
2. 每张优惠券有领取总数量限制。
3. 优惠券被领取后，与当前用户账号绑定。
4. 同一用户不能重复领取同一张优惠券。
5. 优惠券库存不足时不能继续领取。
5.3 优惠券使用
1. 每笔订单只能使用一张优惠券。
2. 满减券需要满足最低消费金额。
3. 折扣券需要满足最低消费金额。
4. 已过期优惠券不能使用。
5. 未领取的优惠券不能使用。
6. 已使用的优惠券不能重复使用。
7. 优惠券只能用于符合适用范围的商品。
8. 订单优惠金额不能超过订单商品总金额。
9. 优惠券不能与其他优惠券叠加使用。
5.4 优惠券状态
优惠券分为：
- 未领取
- 未使用
- 已使用
- 已过期
6. 订单管理
6.1 创建订单
用户可以从购物车提交订单。

创建订单时需要：
1. 检查用户登录状态。
2. 检查购物车是否存在有效商品。
3. 检查商品是否仍然上架。
4. 检查商品库存是否充足。
5. 重新计算商品价格。
6. 检查优惠券是否满足使用条件。
7. 生成唯一订单编号。
8. 记录订单商品明细、商品价格、优惠金额和订单应付金额。
订单金额计算公式：
商品总金额 = Σ（商品单价 × 购买数量）

优惠后金额 = 商品总金额 - 优惠金额


订单金额必须大于等于 0。
6.2 订单状态
订单状态包括：
状态	说明
待支付	订单创建成功，尚未支付
已支付	用户支付成功
已取消	用户或系统取消订单
已完成	订单交易完成
退款中	用户已提交退款申请
已退款	退款成功

6.3 订单取消
1. 普通用户只能取消自己的订单。
2. 待支付订单允许用户主动取消。
3. 已支付订单不能直接取消，需要申请退款。
4. 已取消订单不能再次支付。
5. 订单取消后，优惠券应恢复为未使用状态。
6. 订单取消后，商品库存应恢复。
7. 支付管理
7.1 支付流程
1. 用户只能支付待支付状态的订单。
2. 支付成功后，订单状态变更为已支付。
3. 支付失败时，订单保持待支付状态。
4. 已支付订单不能重复支付。
5. 支付金额必须与订单应付金额一致。
6. 支付成功后需要记录支付流水号。
7.2 支付超时
1. 订单创建后，超过 30 分钟未支付，系统自动取消订单。
2. 自动取消后，优惠券恢复为未使用状态。
3. 自动取消后，商品库存恢复。
4. 已支付订单不能被超时任务取消。
8. 退款管理
8.1 申请退款
1. 用户只能对自己的已支付订单申请退款。
2. 已取消订单不能申请退款。
3. 已退款订单不能重复申请退款。
4. 用户申请退款时需要填写退款原因。
5. 管理员可以查看和处理退款申请。
8.2 退款处理
1. 管理员可以同意或拒绝退款。
2. 同意退款后，订单状态变更为已退款。
3. 拒绝退款后，订单恢复为已支付状态。
4. 退款金额不能超过实际支付金额。
9. 管理后台
管理员可以：
- 新增、修改、下架商品。
- 调整商品库存。
- 创建、修改、停用优惠券。
- 查看所有用户订单。
- 查询指定用户的订单。
- 处理退款申请。
业务规则：
1. 停用优惠券后，用户不能再领取或使用该优惠券。
2. 已经使用的优惠券不能通过修改配置影响历史订单金额。
3. 管理员修改商品价格后，新订单使用最新价格。
4. 历史订单保留创建时的商品价格。
10. 非功能需求
1. 商品列表正常查询应在 2 秒内返回。
2. 订单提交接口正常情况下应在 3 秒内返回。
3. 同一优惠券不能被同一用户重复领取。
4. 并发购买不能出现库存超卖。
5. 用户不能通过修改请求参数访问其他用户订单。
6. 订单金额必须由服务端计算，不能直接信任客户端传入的金额。

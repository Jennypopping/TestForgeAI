# 会议室预约系统产品需求文档（PRD）

版本：V1.0  
状态：需求评审中

## 1. 产品概述

开发一套企业内部会议室预约系统，员工可以查看会议室信息、预约会议室、取消预约，管理员可以管理会议室和查看预约记录。

## 2. 用户角色

- 普通员工：查看会议室、创建和取消自己的预约。
- 管理员：管理会议室、查看所有预约记录。

## 3. 核心功能

### 3.1 会议室列表

- 展示会议室名称、位置、容纳人数和设备信息。
- 支持按照容纳人数筛选会议室。
- 已停用的会议室不允许预约。

### 3.2 创建预约

- 员工选择会议室、预约日期、开始时间和结束时间。
- 必须填写会议主题。
- 预约成功后生成唯一预约编号。
- 同一会议室的预约时间不能重叠。
- 预约开始时间必须早于结束时间。
- 每次预约最长不超过 4 小时。

### 3.3 取消预约

- 员工可以取消自己创建的预约。
- 管理员可以取消任意预约。
- 已取消的预约不再占用会议室时间。

### 3.4 预约记录

- 员工只能查看自己的预约记录。
- 管理员可以查看所有员工的预约记录。
- 预约状态包括：待开始、进行中、已结束、已取消。

### 3.5 会议室管理

- 管理员可以新增、编辑和停用会议室。
- 会议室名称不能重复。
- 停用会议室前需要检查是否存在未结束的预约。

## 4. 业务规则

1. 每个员工每天最多创建 3 条预约。
2. 预约只能提前 7 天创建。
3. 会议室容纳人数必须大于 0。
4. 预约时间按照系统时区计算。
5. 取消预约后，其他员工可以重新预约该时间段。
6. 已开始的预约不能由普通员工取消。

## 5. 非功能需求

- 预约提交后应在 3 秒内返回处理结果。
- 同一会议室在相同时间段不能出现重复预约。
- 普通员工不能通过修改请求参数查看其他员工的预约记录。

## 6. 待确认问题

- Q1：预约时间是否允许精确到分钟，还是只能选择整点或半点？
- Q2：预约开始前多久允许取消？
- Q3：员工每天最多 3 条预约，是指创建次数还是有效预约数量？
- Q4：管理员停用存在未来预约的会议室时，是否需要自动取消这些预约？

## 7. 需求补充与待评审事项

- 普通员工每天最多创建 3 条预约。
- 预约最长不超过 4 小时。
- 已开始的预约不能由普通员工取消。
- 管理员可以取消任意预约。
